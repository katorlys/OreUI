## 大小和颜色

Spinner 使用 current 字体大小和文本颜色。

```html
<span style="font-size: 2rem; color: #52A535;">
  <ore-spinner aria-label="Loading worlds"></ore-spinner>
</span>
```

## 装饰用途

当附近的文本已经能够描述加载状态时，对辅助技术隐藏 Spinner。

```html
<ore-spinner aria-hidden="true"></ore-spinner> <span>Loading worlds</span>
```

## 无障碍

Spinner 使用 `role="status"`，默认标签为 `Loading`。当它仅用于装饰作用时，应设置更具体的 `aria-label`，或使用 `aria-hidden="true"`。  
启用 reduced motion 效果后，动画会停止。
