## Size and color

Spinner uses the current font size and text color.

```html
<span style="font-size: 2rem; color: #52A535;">
  <ore-spinner aria-label="Loading worlds"></ore-spinner>
</span>
```

## Decorative

Hide the Spinner from assistive technology when nearby text already describes the loading state.

```html
<ore-spinner aria-hidden="true"></ore-spinner> <span>Loading worlds</span>
```

## Accessibility

Spinner uses `role="status"` and the default label `Loading`. When it is decorative, set a more specific `aria-label`, or use `aria-hidden="true"`.  
Animation stops when reduced motion is enabled.
