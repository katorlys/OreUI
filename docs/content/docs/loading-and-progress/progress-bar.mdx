## Labels

The labeled variant shows a percentage by default. Set `label` to display custom text.

```html
<ore-progress-bar
  value="65"
  variant="labeled"
  label="Loading resources"
></ore-progress-bar>
<ore-progress-bar
  value="65"
  variant="labeled"
  label-position="top"
  label-align="start"
></ore-progress-bar>
```

Custom label markup can use the public label class:

```html
<ore-progress-bar value="65" variant="labeled">
  <span class="ore-progress-bar-label">65 of 100 chunks</span>
</ore-progress-bar>
```

## API

| Property        | Attribute        | Type                         | Default    |
| --------------- | ---------------- | ---------------------------- | ---------- |
| `label`         | `label`          | `string`                     | `""`       |
| `labelAlign`    | `label-align`    | `"center" \|"end" \|"start"` | `"center"` |
| `labelPosition` | `label-position` | `"bottom" \|"top"`           | `"bottom"` |
| `max`           | `max`            | `number`                     | `100`      |
| `value`         | `value`          | `number`                     | `0`        |
| `variant`       | `variant`        | `"labeled" \|"plain"`        | `"plain"`  |

## Public classes

| Class                     | Purpose                    |
| ------------------------- | -------------------------- |
| `.ore-progress-bar-track` | Progress track and fill    |
| `.ore-progress-bar-label` | Percentage or custom label |

## Accessibility

Progress Bar uses `role="progressbar"` and keeps `aria-valuemin`, `aria-valuemax`, and `aria-valuenow` in sync. Custom label is exposed through `aria-valuetext`.
