## Labels

Use an adjacent `output` when progress needs a visible label. Place it before or after the progress element to choose the label position.

```html
<progress
  class="ore-progress-bar"
  value="65"
  max="100"
  aria-labelledby="download-label"
></progress>
<output class="ore-progress-bar-label" id="download-label">65%</output>

<output class="ore-progress-bar-label" data-align="start" id="chunks-label"
  >65 of 100 chunks</output
>
<progress
  class="ore-progress-bar"
  value="65"
  max="100"
  aria-labelledby="chunks-label"
></progress>
```

## API

Progress Bar accepts the standard attributes of the HTML `progress` element, including `value` and `max`. Omit `value` for an indeterminate progress state.

## Public classes

| Class                     | Purpose                 |
| ------------------------- | ----------------------- |
| `.ore-progress-bar`       | Native progress element |
| `.ore-progress-bar-label` | Optional visible label  |

## CSS variables

| Variable                   | Purpose                     |
| -------------------------- | --------------------------- |
| `--ore-progress-bar-unit`  | Base size unit              |
| `--ore-progress-bar-frame` | Frame and empty track color |
| `--ore-progress-bar-fill`  | Filled track color          |
| `--ore-progress-bar-label` | Label text color            |

## Accessibility

The native `progress` element provides progressbar semantics and value information. Give it an accessible name with `aria-label` or `aria-labelledby`; a visible `output` can provide that name.
