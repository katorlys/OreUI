## 大小和颜色

Progress Ring 使用 current 字体大小和文本颜色。

```html
<span style="font-size: 2rem; color: #52A535;">
  <span
    class="ore-progress-ring"
    style="--ore-progress-ring-frame: 6"
    role="progressbar"
    aria-label="World generation progress"
    aria-valuemin="0"
    aria-valuemax="100"
    aria-valuenow="40"
  ></span>
</span>
```

## 当前值和最大值

将 `--ore-progress-ring-frame` 设置为 `0` 到 `15`，并使用标准 progressbar ARIA 属性公开实际数值。根据当前值和最大值计算：

```text
frame = min(15, floor(clamp(value, 0, max) / max * 16))
```

```html
<span
  class="ore-progress-ring"
  style="--ore-progress-ring-frame: 6"
  role="progressbar"
  aria-label="Chunks loaded"
  aria-valuemin="0"
  aria-valuemax="8"
  aria-valuenow="3"
></span>
```

SVG 一共包含 16 帧。标准化后的进度会被划分为相等的 6.25% 区间：第 0 帧对应 `[0%, 6.25%)`，第 1 帧对应 `[6.25%, 12.5%)`，......，第 15 帧对应 `[93.75%, 100%]`。

## CSS 变量

| 变量                        | 用途                     |
| --------------------------- | ------------------------ |
| `--ore-progress-ring-frame` | `0` 到 `15` 的 sprite 帧 |

## 无障碍

Progress Ring 本身只是 CSS 视觉。请添加 `role="progressbar"`、`aria-valuemin`、`aria-valuemax` 和 `aria-valuenow`，并使用 `aria-label` 或 `aria-labelledby` 提供无障碍名称。进度变化时应同时更新帧和 ARIA 数值。
