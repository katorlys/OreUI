## CSS 类

若有其他元素只需要滚动条的视觉样式，使用 `.ore-scrollbar`。

```html
<div class="ore-scrollbar" style="max-height: 12rem; overflow: auto;">
  Scrollable content
</div>
```

该类不会添加 Scrollbar 提供的键盘行为和自动 `tabindex` 管理功能。

## 无障碍

Scrollbar 仅在内容溢出时进入 `Tab` 顺序。按`方向键`可小幅滚动，按 `Page Up` 和 `Page Down` 可滚动一个 viewport，按 `Home` 和 `End` 可移动到任一边缘。应设置描述滚动区域的无障碍标签。
