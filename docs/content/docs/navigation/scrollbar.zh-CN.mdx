## 原生滚动

将 `.ore-scrollbar` 应用于真实的 overflow 容器。滚轮、触摸惯性和滚动位置继续绑定到这个原生容器。可选的 `oreui-web/scrollbar` controller 根据实际溢出管理 `tabindex`、统一各浏览器的键盘滚动，并提供 Firefox 视觉 fallback。

```html
<div class="ore-scrollbar" style="max-height: 12rem; overflow: auto;">
  Scrollable content
</div>
```

Chromium 和 Safari 使用 `::-webkit-scrollbar*` 复刻分层像素滑块。由于 Firefox 没有提供所需的 thumb 和 track 伪元素，controller 会隐藏其原生滚动条并覆盖同样的 track 和 thumb 分层，同时仍以真实元素作为滚动容器。覆盖层同步原生滚动位置和指针拖拽。未导入 controller 时，Firefox 使用 `scrollbar-color` 和原生滚动条作为 fallback。

## CSS 变量

| 变量                               | 用途               |
| ---------------------------------- | ------------------ |
| `--ore-scrollbar-unit`             | 基础尺寸单位       |
| `--ore-scrollbar-size`             | 垂直滚动条宽度     |
| `--ore-scrollbar-horizontal-size`  | 水平滚动条高度     |
| `--ore-scrollbar-track-size`       | 轨道线条粗细       |
| `--ore-scrollbar-thumb-min-size`   | 滑块最小长度       |
| `--ore-scrollbar-track`            | 轨道颜色           |
| `--ore-scrollbar-thumb-border`     | 滑块边框颜色       |
| `--ore-scrollbar-thumb-highlight`  | 滑块高光颜色       |
| `--ore-scrollbar-thumb-background` | 滑块背景颜色       |
| `--ore-scrollbar-thumb-shadow`     | 滑块阴影颜色       |

## 无障碍

导入 controller 后，发生溢出且没有设置 `tabindex` 的区域会获得 `tabindex="0"`，没有溢出的区域会获得 `tabindex="-1"`。显式设置的 `tabindex`（包括 `-1`）永远不会被覆盖。只有滚动区域自身获得焦点时，controller 才统一处理方向键、Page Up/Down、Home 和 End，因此内部控件保留原生键盘行为。请使用 `aria-label` 或 `aria-labelledby` 来提供无障碍名称。
