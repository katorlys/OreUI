## Public classes

| Class                      | Purpose                      |
| -------------------------- | ---------------------------- |
| `.ore-navbar-start`        | Leading controls             |
| `.ore-navbar-title`        | Centered screen title        |
| `.ore-navbar-actions`      | Trailing action group        |
| `.ore-navbar-button`       | Square icon action           |
| `.ore-navbar-action`       | Text or icon-and-text action |
| `.ore-navbar-action-label` | Action text alignment        |

## CSS variables

| Variable                         | Purpose                  |
| -------------------------------- | ------------------------ |
| `--ore-navbar-unit`              | Base size unit           |
| `--ore-navbar-background`        | Navigation background    |
| `--ore-navbar-bottom-shadow`     | Bottom bevel color       |
| `--ore-navbar-shadow`            | Outer drop shadow color  |
| `--ore-navbar-foreground`        | Text and icon color      |
| `--ore-navbar-action-background` | Action background        |
| `--ore-navbar-action-highlight`  | Action leading highlight |
| `--ore-navbar-action-shadow`     | Action leading shadow    |
| `--ore-navbar-text-offset`       | Vertical text offset     |
| `--ore-navbar-icon-offset`       | Vertical icon offset     |

## Accessibility

Navbar uses `role="navigation"` unless another role is provided. Add an accessible label when the page contains more than one navigation, and label icon-only buttons in it.
