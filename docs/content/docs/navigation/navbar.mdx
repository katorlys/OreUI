## Public classes

| Class                      | Purpose                      |
| -------------------------- | ---------------------------- |
| `.ore-navbar-start`        | Leading controls             |
| `.ore-navbar-title`        | Centered screen title        |
| `.ore-navbar-actions`      | Trailing action group        |
| `.ore-navbar-button`       | Square icon action           |
| `.ore-navbar-action`       | Text or icon-and-text action |
| `.ore-navbar-action-label` | Action text alignment        |

## Accessibility

Navbar uses `role="navigation"` unless another role is provided. Add an accessible label when the page contains more than one navigation, and label icon-only buttons in it.
