## 选择

Tab Button 在最近的 Tab Bar 中管理选择状态，并在选中新的标签时触发 `change` 事件。

```js
const tabBar = document.querySelector("ore-tab-bar");
tabBar?.addEventListener("change", (event) => {
  const selected = event.target;
  console.log(selected);
});
```

## 无障碍

Tab Bar 使用 `role="tablist"`。设置无障碍标签，并使用 Tab Button 作为其直接交互子元素。  
更多信息请见 [Tab Button](../../buttons/tab-button#无障碍)。
