## Selection

Tab Buttons manage selection within their nearest Tab Bar and dispatch `change` when a new tab is selected.

```js
const tabBar = document.querySelector("ore-tab-bar");
tabBar?.addEventListener("change", (event) => {
  const selected = event.target;
  console.log(selected);
});
```

## Accessibility

Tab Bar uses `role="tablist"`. Add an accessible label and use Tab Button as its direct interactive children.  
For more information, see [Tab Button](../../buttons/tab-button#accessibility).
