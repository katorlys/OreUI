## 公开类

| 类                         | 用途                         |
| -------------------------- | ---------------------------- |
| `.ore-navbar-start`        | 起始位置的控件               |
| `.ore-navbar-title`        | 居中的屏幕标题               |
| `.ore-navbar-actions`      | 末尾的操作组                 |
| `.ore-navbar-button`       | 方形图标操作按钮             |
| `.ore-navbar-action`       | 文字或“图标加文字”的操作按钮 |
| `.ore-navbar-action-label` | 操作文字的对齐方式           |

## 无障碍

Navbar 使用 `role="navigation"`，除非提供了其他角色。当页面包含多个导航栏时，请设置无障碍标签，并为其中仅含图标的按钮设置无障碍标签。
