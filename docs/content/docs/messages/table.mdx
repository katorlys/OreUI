## Sorting

Put a button with `.ore-table-sort` inside a header with `aria-sort`. Its `value` identifies the column.

```html
<th scope="col" aria-sort="none">
  <button class="ore-table-sort" type="button" value="players">
    Players
    <span class="ore-table-sort-indicator" aria-hidden="true"></span>
  </button>
</th>
```

The `sort` event provides the column and the next direction. The data sorting functionality should be provided by your application.

```js
table.addEventListener("sort", (event) => {
  console.log(event.detail.column, event.detail.direction);
});
```

In React, use `onSort`.

## API

| Property  | Attribute | Type                   | Default   |
| --------- | --------- | ---------------------- | --------- |
| `variant` | `variant` | `"plain" \| "striped"` | `"plain"` |

| Event  | Detail                                                                 |
| ------ | ---------------------------------------------------------------------- |
| `sort` | `{ column: string; direction: "none" \| "ascending" \| "descending" }` |

## Public classes

| Class                          | Purpose                            |
| ------------------------------ | ---------------------------------- |
| `.ore-table-row-header-column` | Row-header column width            |
| `.ore-table-data-column`       | Data column width                  |
| `.ore-table-corner`            | Empty top-left corner cell         |
| `.ore-table-sort`              | Sortable header button             |
| `.ore-table-sort-indicator`    | Ascending and descending indicator |

## Accessibility

Keep the native table structure, add a caption, and use `scope` on headers.  
Sorting updates `aria-sort`. Announce results when there are no changes.
