## Overlays
Place labels over media with the overlay classes.

```html
<div class="ore-card-media">
	<img src="/world.webp" alt="A forest village" />
	<ore-tag class="ore-card-overlay-top-start">New</ore-tag>
</div>
```

## Public classes
|Class|Purpose|
|---|---|
|`.ore-card-media`|16:9 media area|
|`.ore-card-body`|Caption and action row|
|`.ore-card-caption`|Title and description group|
|`.ore-card-title`|Primary label|
|`.ore-card-description`|Supporting text|
|`.ore-card-meta`|Short trailing metadata|
|`.ore-card-action`|Trailing Icon Button|
|`.ore-card-overlay-top-start`|Top-start media overlay|
|`.ore-card-overlay-bottom-start`|Bottom-start media overlay|
|`.ore-card-overlay-top-end`|Top-end media overlay|
