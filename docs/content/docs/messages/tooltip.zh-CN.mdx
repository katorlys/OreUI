## 位置
可选 `side="top"`、`"right"`、`"bottom"` 或 `"left"`。页面滚动和调整大小时，位置会一起更新。

## 延迟
`delay` 是 Tooltip 显示前的等待时间，单位为毫秒。默认值：`500`。

```html
<ore-tooltip delay="200">...</ore-tooltip>
```

## 事件
`open` 变化后会触发 `open-change`，其 `detail` 是新的 boolean 状态。  
对于 React，请使用 `onOpenChange`。

## API
|Prop|属性|类型|默认值|
|---|---|---|---|
|`defaultOpen`|`default-open`|`boolean`|`false`|
|`delay`|`delay`|`number`|`500`|
|`open`|`open`|`boolean`|`false`|
|`side`|`side`|`"top" \| "right" \| "bottom" \| "left"`|`"top"`|

## 公开类
|类|用途|
|---|---|
|`.ore-tooltip-trigger`|由 Tooltip 描述的元素|
|`.ore-tooltip-content`|弹出内容|
|`.ore-tooltip-arrow`|方向箭头|

## 无障碍
Tooltip 使用 `aria-describedby` 关联触发器与内容，并在指针移出或按下 `Esc` 时关闭。
