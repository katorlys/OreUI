## 默认状态

使用 `default-open` 将 Accordion 的初始默认状态设置为展开状态。当由应用程序控制其状态时，应设置 `open` 属性。

```html
<ore-accordion default-open>...</ore-accordion>
```

## 事件

`open` 属性发生变化后会触发 `open-change`。其 `detail` 是新的 boolean 状态。

```js
accordion.addEventListener("open-change", (event) => {
  console.log(event.detail);
});
```

对于 React，请使用 `onOpenChange`。

## API

| Prop          | 属性           | 类型      | 默认值  |
| ------------- | -------------- | --------- | ------- |
| `defaultOpen` | `default-open` | `boolean` | `false` |
| `open`        | `open`         | `boolean` | `false` |
| `value`       | `value`        | `string`  | `""`    |

## 公开类

| 类                       | 用途               |
| ------------------------ | ------------------ |
| `.ore-accordion-trigger` | 切换内容区域的按钮 |
| `.ore-accordion-title`   | 触发器标签         |
| `.ore-accordion-content` | 可折叠内容         |

## CSS 变量

| 变量                                 | 用途                 |
| ------------------------------------ | -------------------- |
| `--ore-accordion-unit`               | 基础尺寸单位         |
| `--ore-accordion-border`             | 触发器和内容边框颜色 |
| `--ore-accordion-background`         | 展开内容的背景颜色   |
| `--ore-accordion-foreground`         | 触发器文本和图标颜色 |
| `--ore-accordion-content-foreground` | 展开内容的文本颜色   |

## 无障碍

Accordion 使用 `aria-controls` 关联触发器与内容、更新 `aria-expanded`，并隐藏已折叠的内容。应使用真正的按钮作为触发器。
