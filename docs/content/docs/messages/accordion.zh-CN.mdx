## 初始状态

使用原生 `open` 属性让 Accordion 初始保持展开。

```html
<details class="ore-accordion" open>...</details>
```

## 单开组

为相关 details 元素设置相同的原生 `name`，即可保证同一时间只展开一项。

```html
<details class="ore-accordion" name="world-settings">...</details>
<details class="ore-accordion" name="world-settings">...</details>
```

## 事件

`open` 状态变化后会触发标准 `toggle` 事件，可从 `event.currentTarget.open` 读取当前状态。

```js
accordion.addEventListener("toggle", (event) => {
  console.log(event.currentTarget.open);
});
```

React 中使用 `onToggle`。

## API

| Prop   | 属性   | 类型      | 默认值  |
| ------ | ------ | --------- | ------- |
| `open` | `open` | `boolean` | `false` |
| `name` | `name` | `string`  | `""`    |

## 公开类

| 类                       | 用途               |
| ------------------------ | ------------------ |
| `.ore-accordion`         | 原生 details 根元素 |
| `.ore-accordion-title`   | summary 标签        |
| `.ore-accordion-content` | 可折叠内容           |

## 无障碍

原生 details 和 summary 无需 JavaScript 即可提供 disclosure 语义、键盘激活、焦点管理和折叠内容可见性。不要在 summary 内嵌套交互按钮。
