## Open and close

Elements with `.ore-modal-trigger` open the dialog. Elements with `.ore-modal-close` close it. You can also call `show()` and `close(reason)`.

```js
const modal = document.querySelector("ore-modal");
modal.show();
modal.close("close");
```

## Events

`open-change` reports the boolean open state. `modal-close` reports whether the dialog closed through `"backdrop"`, `"close"`, or `"escape"`.

```js
modal.addEventListener("modal-close", (event) => {
  console.log(event.detail.reason);
});
```

In React, use `onOpenChange` and `onModalClose`.

## API

| Property      | Attribute      | Type      | Default |
| ------------- | -------------- | --------- | ------- |
| `defaultOpen` | `default-open` | `boolean` | `false` |
| `open`        | `open`         | `boolean` | `false` |

| Method           | Description                             |
| ---------------- | --------------------------------------- |
| `show()`         | Open the modal                          |
| `close(reason?)` | Close the modal with an optional reason |

## Public classes

| Class                      | Purpose                        |
| -------------------------- | ------------------------------ |
| `.ore-modal-trigger`       | Control that opens the dialog  |
| `.ore-modal-dialog`        | Native dialog element          |
| `.ore-modal-content`       | Dialog frame                   |
| `.ore-modal-header`        | Title bar                      |
| `.ore-modal-title`         | Accessible dialog title        |
| `.ore-modal-description`   | Accessible supporting text     |
| `.ore-modal-close`         | Control that closes the dialog |
| `.ore-modal-header-button` | Header action                  |

## CSS variables

The scrollable body also accepts all [Scrollbar CSS variables](../../navigation/scrollbar#css-variables).

| Variable                         | Purpose                      |
| -------------------------------- | ---------------------------- |
| `--ore-modal-unit`               | Base size unit               |
| `--ore-modal-border`             | Dialog frame color           |
| `--ore-modal-section-background` | Header and footer background |
| `--ore-modal-highlight`          | Section highlight color      |
| `--ore-modal-shadow`             | Section shadow color         |
| `--ore-modal-foreground`         | Dialog text and icon color   |

## Accessibility

Modal uses the native `<dialog>` element for focus containment and Escape handling. It connects the title and description to the dialog, and then restores focus to the control that opened it.
