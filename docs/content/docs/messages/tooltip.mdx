## Placement

Use `data-side="top"`, `"right"`, `"bottom"`, or `"left"` in native HTML. Framework wrappers expose the same setting through the `side` prop. Position updates while the page scrolls or resizes.

## Delay

`data-delay` is the time in milliseconds before the tooltip opens. Default: `500`.

```html
<span class="ore-tooltip" data-delay="200">...</span>
```

## Events

`oreui:openchange` fires after the open state changes. Its `detail` is the new boolean state.
In React, use `onOpenChange`.

## API

| Framework prop | Native attribute    | Type                                     | Default |
| -------------- | ------------------- | ---------------------------------------- | ------- |
| `defaultOpen`  | `data-default-open` | `boolean`                                | `false` |
| `delay`        | `data-delay`        | `number`                                 | `500`   |
| `open`         | `data-open`         | `boolean`                                | unset   |
| `side`         | `data-side`         | `"top" \| "right" \| "bottom" \| "left"` | `"top"` |

## Public classes

| Class                  | Purpose                          |
| ---------------------- | -------------------------------- |
| `.ore-tooltip-trigger` | Element described by the tooltip |
| `.ore-tooltip-content` | Popover content                  |
| `.ore-tooltip-arrow`   | Directional arrow                |

## CSS variables

| Variable                    | Purpose                  |
| --------------------------- | ------------------------ |
| `--ore-tooltip-unit`        | Base size unit           |
| `--ore-tooltip-corner-size` | Cut corner size          |
| `--ore-tooltip-background`  | Tooltip background color |
| `--ore-tooltip-border`      | Tooltip and arrow border |
| `--ore-tooltip-foreground`  | Tooltip text color       |

## Accessibility

Tooltip connects its trigger and content with `aria-describedby` and closes on pointer leave or `Esc`.
