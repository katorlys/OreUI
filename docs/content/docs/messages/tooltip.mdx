## Placement

Use `side="top"`, `"right"`, `"bottom"`, or `"left"`. Position updates while the page scrolls or resizes.

## Delay

`delay` is the time in milliseconds before the tooltip opens. Default: `500`.

```html
<ore-tooltip delay="200">...</ore-tooltip>
```

## Events

`open-change` fires after `open` changes. Its `detail` is the new boolean state.  
In React, use `onOpenChange`.

## API

| Property      | Attribute      | Type                                     | Default |
| ------------- | -------------- | ---------------------------------------- | ------- |
| `defaultOpen` | `default-open` | `boolean`                                | `false` |
| `delay`       | `delay`        | `number`                                 | `500`   |
| `open`        | `open`         | `boolean`                                | `false` |
| `side`        | `side`         | `"top" \| "right" \| "bottom" \| "left"` | `"top"` |

## Public classes

| Class                  | Purpose                          |
| ---------------------- | -------------------------------- |
| `.ore-tooltip-trigger` | Element described by the tooltip |
| `.ore-tooltip-content` | Popover content                  |
| `.ore-tooltip-arrow`   | Directional arrow                |

## Accessibility

Tooltip connects its trigger and content with `aria-describedby` and closes on pointer leave or `Esc`.
