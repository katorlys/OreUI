## Default state

Use `default-open` for an accordion that starts expanded. Set the `open` property when the application controls its state.

```html
<ore-accordion default-open>...</ore-accordion>
```

## Events

`open-change` fires after `open` changes. Its `detail` is the new boolean state.

```js
accordion.addEventListener("open-change", (event) => {
  console.log(event.detail);
});
```

In React, use `onOpenChange`.

## API

| Property      | Attribute      | Type      | Default |
| ------------- | -------------- | --------- | ------- |
| `defaultOpen` | `default-open` | `boolean` | `false` |
| `open`        | `open`         | `boolean` | `false` |
| `value`       | `value`        | `string`  | `""`    |

## Public classes

| Class                    | Purpose                         |
| ------------------------ | ------------------------------- |
| `.ore-accordion-trigger` | Button that toggles the section |
| `.ore-accordion-title`   | Trigger label                   |
| `.ore-accordion-content` | Collapsible content             |

## Accessibility

Accordion links the trigger and content with `aria-controls`, updates `aria-expanded`, and hides collapsed content. Use a real button for the trigger.
