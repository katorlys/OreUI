## Initial state

Use the native `open` attribute for an accordion that starts expanded.

```html
<details class="ore-accordion" open>...</details>
```

## Exclusive group

Give related details elements the same native `name` to keep only one item open.

```html
<details class="ore-accordion" name="world-settings">...</details>
<details class="ore-accordion" name="world-settings">...</details>
```

## Events

The standard `toggle` event fires after the `open` state changes. Read the current state from `event.currentTarget.open`.

```js
accordion.addEventListener("toggle", (event) => {
  console.log(event.currentTarget.open);
});
```

In React, use `onToggle`.

## API

| Property | Attribute | Type      | Default |
| -------- | --------- | --------- | ------- |
| `open`   | `open`    | `boolean` | `false` |
| `name`   | `name`    | `string`  | `""`    |

## Public classes

| Class                    | Purpose             |
| ------------------------ | ------------------- |
| `.ore-accordion`         | Native details root |
| `.ore-accordion-title`   | Summary label       |
| `.ore-accordion-content` | Collapsible content |

## Accessibility

The native details and summary elements provide disclosure semantics, keyboard activation, focus handling, and collapsed-content visibility without JavaScript. Do not place an interactive button inside summary.
