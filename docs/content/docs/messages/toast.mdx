## Open and close

Toast is closed by default. Set `open`, call `show()`, or call `close()` on the element. The `open-change` event reports controlled state changes.

```js
const toast = document.querySelector("ore-toast");
toast.show();
toast.addEventListener("open-change", (event) => {
  console.log(event.detail); // true or false
});
```

## Duration and position

`duration` defaults to `3000` ms. Set it to `0` to keep the Toast open until `close()` is called. The default position is `bottom-center`; use `top-start`, `top-center`, `top-end`, `bottom-start`, or `bottom-end` for another viewport corner or edge.

```html
<ore-toast open duration="5000" position="top-end" aria-label="Settings saved">
  Saved
</ore-toast>
```

## Color

Toast uses the same background variants as Tag: `neutral`, `secondary`, `primary`, `informative`, `notice`, `warning`, and `realms-informative`. The host also accepts `class` and `--ore-toast-*` variables.

## Events

`open-change` fires when the `open` state changes. Its `detail` is the new boolean state.  
In React, use `onOpenChange`.

## API

| Property      | Attribute      | Type                                                                                                      | Default           |
| ------------- | -------------- | --------------------------------------------------------------------------------------------------------- | ----------------- |
| `defaultOpen` | `default-open` | `boolean`                                                                                                 | `false`           |
| `duration`    | `duration`     | `number`                                                                                                  | `3000`            |
| `open`        | `open`         | `boolean`                                                                                                 | `false`           |
| `position`    | `position`     | `"top-start" \| "top-center" \| "top-end" \| "bottom-start" \| "bottom-center" \| "bottom-end"`           | `"bottom-center"` |
| `variant`     | `variant`      | `"neutral" \| "secondary" \| "primary" \| "informative" \| "notice" \| "warning" \| "realms-informative"` | `"neutral"`       |

| Method    | Description                                   |
| --------- | --------------------------------------------- |
| `show()`  | Open the Toast and start its duration timer   |
| `close()` | Close the Toast and cancel its duration timer |

The Toast has no public child classes. Use the host `class` for layout and `--ore-toast-*` variables for component details.

## CSS variables

| Variable                 | Purpose                         |
| ------------------------ | ------------------------------- |
| `--ore-toast-unit`       | Base size unit                  |
| `--ore-toast-inset`      | Distance from the viewport edge |
| `--ore-toast-background` | Toast background color          |
| `--ore-toast-foreground` | Toast text color                |
| `--ore-toast-border`     | Toast border color              |
| `--ore-toast-shadow`     | Toast shadow color              |

## Accessibility

Toast uses `role="status"`, `aria-live="polite"`, and `aria-atomic="true"` so short status messages do not interrupt the current task. Always provide an accessible name with `aria-label` or `aria-labelledby`. Keep the message concise and do not use Toast for actions that require a user decision.
