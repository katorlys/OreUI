## Open and close

Toast is closed by default. Use `data-default-open` for its initial state, `data-open` for controlled state, or call `showToast()` and `closeToast()`. The `oreui:openchange` event reports actual Popover state changes.

```js
import { closeToast, showToast } from "oreui-web/toast";

const toast = document.querySelector(".ore-toast");
showToast(toast);
toast.addEventListener("oreui:openchange", (event) => {
  console.log(event.detail); // true or false
});
closeToast(toast);
```

## Duration and position

`data-duration` defaults to `3000` ms. Set it to `0` to keep the Toast open until `closeToast()` is called. Hovering the Toast or moving focus inside it pauses the remaining time. The default position is `bottom-center`; use `top-start`, `top-center`, `top-end`, `bottom-start`, or `bottom-end` for another viewport corner or edge.

```html
<div
  class="ore-toast"
  data-default-open
  data-duration="5000"
  data-position="top-end"
  aria-label="Settings saved"
>
  Saved
</div>
```

## Color

Toast uses the same background variants as Tag: `neutral`, `secondary`, `primary`, `informative`, `notice`, `warning`, and `realms-informative`. The host also accepts `class` and `--ore-toast-*` variables.

## Events

`oreui:openchange` fires when the Popover state changes. Its `detail` is the new boolean state.
In React, use `onOpenChange`.

## API

| Option          | Attribute           | Type                                                                                                      | Default           |
| --------------- | ------------------- | --------------------------------------------------------------------------------------------------------- | ----------------- |
| Initial open    | `data-default-open` | presence                                                                                                  | absent            |
| Duration        | `data-duration`     | `number`                                                                                                  | `3000`            |
| Controlled open | `data-open`         | presence                                                                                                  | absent            |
| Position        | `data-position`     | `"top-start" \| "top-center" \| "top-end" \| "bottom-start" \| "bottom-center" \| "bottom-end"`           | `"bottom-center"` |
| Variant         | `data-variant`      | `"neutral" \| "secondary" \| "primary" \| "informative" \| "notice" \| "warning" \| "realms-informative"` | `"neutral"`       |

| Helper         | Description                                   |
| -------------- | --------------------------------------------- |
| `showToast()`  | Open the Toast and start its duration timer   |
| `closeToast()` | Close the Toast and cancel its duration timer |

The Toast has no public child classes. Use the host `class` for layout and `--ore-toast-*` variables for component details.

## CSS variables

| Variable                 | Purpose                         |
| ------------------------ | ------------------------------- |
| `--ore-toast-unit`       | Base size unit                  |
| `--ore-toast-inset`      | Distance from the viewport edge |
| `--ore-toast-background` | Toast background color          |
| `--ore-toast-foreground` | Toast text color                |
| `--ore-toast-border`     | Toast border color              |
| `--ore-toast-shadow`     | Toast shadow color              |

## Accessibility

Toast uses `role="status"`, `aria-live="polite"`, and `aria-atomic="true"` so short status messages do not interrupt the current task. Always provide an accessible name with `aria-label` or `aria-labelledby`. Keep the message concise and do not use Toast for actions that require a user decision.
