## Variants

```html
<ore-tag>Neutral</ore-tag>
<ore-tag variant="secondary">Secondary</ore-tag>
<ore-tag variant="primary">Primary</ore-tag>
<ore-tag variant="informative">Info</ore-tag>
<ore-tag variant="notice">Notice</ore-tag>
<ore-tag variant="warning">Warning</ore-tag>
<ore-tag variant="realms-informative">Realms</ore-tag>
```

Add `outlined` to add a visible border to the label.

```html
<ore-tag outlined>Outlined</ore-tag>
```

## API

| Property   | Attribute  | Type                                                                                                      | Default     |
| ---------- | ---------- | --------------------------------------------------------------------------------------------------------- | ----------- |
| `outlined` | `outlined` | `boolean`                                                                                                 | `false`     |
| `variant`  | `variant`  | `"neutral" \| "secondary" \| "primary" \| "informative" \| "notice" \| "warning" \| "realms-informative"` | `"neutral"` |

## CSS variables

| Variable               | Purpose          |
| ---------------------- | ---------------- |
| `--ore-tag-background` | Label background |
| `--ore-tag-foreground` | Label text color |
| `--ore-tag-border`     | Outline color    |
