import { useRef } from "react";

export function FormModal() {

    <button type="button" onClick={() => modal.current?.showModal()}>Open modal</button>

  </>;
}

## 打开和关闭

调用原生 `showModal()` 以模态方式打开对话框。`form[method="dialog"]` 会关闭对话框而不提交数据，被激活提交按钮的 `value` 会写入 `dialog.returnValue`。

可选 controller 还支持使用 `data-modal-target` 指向对话框 `id`。只有关闭控件无法放入 dialog form 时，才使用 `data-modal-close="value"`。

```js
const modal = document.querySelector("dialog.ore-modal");
modal.showModal();
modal.close("cancel");
```

## 事件

关闭后会触发原生 `close`，用户按 Escape 请求关闭时会触发原生 `cancel`。从 `returnValue` 读取关闭结果，可选 controller 会为 backdrop 和 Escape 分别写入 `"backdrop"` 与 `"escape"`。

```js
modal.addEventListener("close", () => {
  console.log(modal.returnValue);
});
```

## 原生 API

| 成员 | 用途 |
| --- | --- |
| `open` | 反映对话框是否打开 |
| `returnValue` | `close()` 或 dialog form 提供的值 |
| `showModal()` | 在 top layer 中以模态方式打开 |
| `close(value?)` | 关闭并可选设置返回值 |

## 公开类

| 类 | 用途 |
| --- | --- |
| `.ore-modal` | 原生 dialog 根 |
| `.ore-modal-content` | 对话框框架 |
| `.ore-modal-header` | 标题栏 |
| `.ore-modal-title` | 可访问的对话框标题 |
| `.ore-modal-description` | 可访问的辅助文本 |
| `.ore-modal-header-button` | 标题栏操作 |
| `.modal-form-body` | 可滚动深色表单区 |
| `.modal-confirmation` | 确认选项区 |
| `.modal-actions` | 对话框操作区 |

## 无障碍

原生 dialog 提供 top layer、焦点限制、背景 inert、Escape 处理和关闭后的焦点恢复。请显式设置 `aria-labelledby`，并按需设置 `aria-describedby`。
