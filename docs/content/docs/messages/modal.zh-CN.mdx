## 打开和关闭

带有 `.ore-modal-trigger` 的元素用于打开对话框，带有 `.ore-modal-close` 的元素用于关闭对话框。也可调用 `show()` 和 `close(reason)`。

```js
const modal = document.querySelector("ore-modal");
modal.show();
modal.close("close");
```

## 事件

`open-change` 反映打开状态的 boolean 值，`modal-close` 反映对话框是通过 `"backdrop"`、`"close"` 还是 `"escape"` 关闭的。

```js
modal.addEventListener("modal-close", (event) => {
  console.log(event.detail.reason);
});
```

对于 React，请使用 `onOpenChange` 和 `onModalClose`。

## API

| Prop          | 属性           | 类型      | 默认值  |
| ------------- | -------------- | --------- | ------- |
| `defaultOpen` | `default-open` | `boolean` | `false` |
| `open`        | `open`         | `boolean` | `false` |

| 方法             | 描述                         |
| ---------------- | ---------------------------- |
| `show()`         | 打开 Modal                   |
| `close(reason?)` | 关闭 Modal，以及（可选）原因 |

## 公开类

| 类                         | 用途               |
| -------------------------- | ------------------ |
| `.ore-modal-trigger`       | 打开对话框的控件   |
| `.ore-modal-dialog`        | 原生对话框元素     |
| `.ore-modal-content`       | 对话框框架         |
| `.ore-modal-header`        | 标题栏             |
| `.ore-modal-title`         | 可访问的对话框标题 |
| `.ore-modal-description`   | 可访问的辅助文本   |
| `.ore-modal-close`         | 关闭对话框的控件   |
| `.ore-modal-header-button` | 标题栏操作         |

## 无障碍

Modal 使用原生 `<dialog>` 元素来限制焦点和处理 `Esc` 键。它将标题和描述关联到对话框，在关闭后将焦点恢复到打开它的控件上。
