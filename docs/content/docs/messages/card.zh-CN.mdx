## 叠加层

使用叠加层类将标签放置在媒体之上。

```html
<div class="ore-card-media">
  <img src="/world.webp" alt="A forest village" />
  <ore-tag class="ore-card-overlay-top-start">New</ore-tag>
</div>
```

## 公开类

| 类                               | 用途             |
| -------------------------------- | ---------------- |
| `.ore-card-media`                | 16:9 媒体区域    |
| `.ore-card-body`                 | 说明文字和操作行 |
| `.ore-card-caption`              | 标题和描述组     |
| `.ore-card-title`                | 主要标签         |
| `.ore-card-description`          | 辅助文本         |
| `.ore-card-meta`                 | 末尾的简短元数据 |
| `.ore-card-action`               | 末尾的图标按钮   |
| `.ore-card-overlay-top-start`    | 媒体左上方叠加层 |
| `.ore-card-overlay-bottom-start` | 媒体左下方叠加层 |
| `.ore-card-overlay-top-end`      | 媒体右上方叠加层 |
