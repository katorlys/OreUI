Divider fills the available width. Use the host `class` or ordinary CSS to control its width and surrounding spacing.

## CSS variables

| Variable              | Purpose                 |
| --------------------- | ----------------------- |
| `--ore-divider-unit`  | Thickness of each line  |
| `--ore-divider-dark`  | Color of the upper line |
| `--ore-divider-light` | Color of the lower line |

## Accessibility

Divider has `role="separator"` by default and represents a horizontal separation between sections. When the line is only used for decoration and does not separate content, set `role="none"`.
