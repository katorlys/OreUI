## 用法
<Tabs groupId="framework" items={["Vanilla", "React", "Astro"]} persist>

```tsx
import { OreContainer } from "@katorlys/oreui-react/container";

export function WorldSettings() {
	return (
		<OreContainer variant="dark">
			<h2>World settings</h2>
			<p>Choose how players join your world.</p>
		</OreContainer>
	);
}
```

## 变体
```html
<ore-container variant="dark">Dark surface</ore-container>
<ore-container variant="light">Light surface</ore-container>
```

## API
|Prop|属性|类型|默认值|
|---|---|---|---|
|`variant`|`variant`|`"dark" \|"light"`|`"dark"`|

## CSS 变量
|变量|用途|
|---|---|
|`--ore-container-padding`|表面边缘与内容之间的间距|
|`--ore-container-gap`|直接子元素之间的间距|
