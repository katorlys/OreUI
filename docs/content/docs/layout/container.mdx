## Usage

<Tabs groupId="framework" items={["Vanilla", "React", "Vue", "Astro"]} persist>
	<Tab value="Vanilla">
```js
import "oreui-web/container";
```

```html
<ore-container variant="dark">
  <h2>World settings</h2>
  <p>Choose how players join your world.</p>
</ore-container>
```

    </Tab>
    <Tab value="React">

```tsx
import { Container } from "@oreui-web/react/container";

export function WorldSettings() {
  return (
    <Container variant="dark">
      <h2>World settings</h2>
      <p>Choose how players join your world.</p>
    </Container>
  );
}
```

    </Tab>

## Variants

```html
<ore-container variant="dark">Dark surface</ore-container>
<ore-container variant="light">Light surface</ore-container>
```

## API

| Property  | Attribute | Type               | Default  |
| --------- | --------- | ------------------ | -------- |
| `variant` | `variant` | `"dark" \|"light"` | `"dark"` |

## CSS variables

| Variable                  | Purpose                                        |
| ------------------------- | ---------------------------------------------- |
| `--ore-container-padding` | Space between the surface edge and its content |
| `--ore-container-gap`     | Space between direct children                  |
