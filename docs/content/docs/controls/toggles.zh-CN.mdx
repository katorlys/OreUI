```tsx
import { TabButton, Toggles } from "@oreui-web/react/toggles";
import { useState } from "react";

export function DaylightToggles() {
  const [value, setValue] = useState("day");

  return (
    <Toggles aria-label="Daylight cycle">
      <TabButton selected={value === "day"} onChange={() => setValue("day")}>
        Day
      </TabButton>
      <TabButton
        selected={value === "night"}
        onChange={() => setValue("night")}
      >
        Night
      </TabButton>
      <TabButton
        selected={value === "always"}
        onChange={() => setValue("always")}
      >
        Always
      </TabButton>
    </Toggles>
  );
}
```

## 行为

Toggles 设置 `role="tablist"`、排列其子元素，并将 `toggle` 颜色应用在直接或嵌套的 Tab Button 上。  
更多信息请见 [Tab Button](../../buttons/tab-button/)。

## 无障碍

为 Tab 组提供无障碍名称。使用`方向键`在已启用的选项间移动；`Home` 和 `End` 分别选择第一个和最后一个选项。
