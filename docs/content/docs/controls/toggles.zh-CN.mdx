```tsx
import { OreTabButton } from "@katorlys/oreui-react/tab-button";
import { OreToggles } from "@katorlys/oreui-react/toggles";
import { useState } from "react";

export function DaylightToggles() {
  const [value, setValue] = useState("day");

  return (
    <OreToggles aria-label="Daylight cycle">
      <OreTabButton selected={value === "day"} onChange={() => setValue("day")}>
        Day
      </OreTabButton>
      <OreTabButton
        selected={value === "night"}
        onChange={() => setValue("night")}
      >
        Night
      </OreTabButton>
      <OreTabButton
        selected={value === "always"}
        onChange={() => setValue("always")}
      >
        Always
      </OreTabButton>
    </OreToggles>
  );
}
```

## 行为

Toggles 设置 `role="tablist"`、排列其子元素，并将 `toggle` 颜色应用在直接或嵌套的 Tab Button 上。  
更多信息请见 [Tab Button](../../buttons/tab-button/)。

## 无障碍

为 Tab 组提供无障碍名称。使用`方向键`在已启用的选项间移动；`Home` 和 `End` 分别选择第一个和最后一个选项。
