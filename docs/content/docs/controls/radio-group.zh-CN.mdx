## 行为

原生 `fieldset` 对相关 Radio 进行分组，`.ore-radio-group` 提供间距。
更多信息请见 [Radio](../radio)。

## 无障碍

使用 `legend` 为每个组命名。所有子选项应共用一个 `name`。
更多信息请见 [Radio](../radio#无障碍)。
