## 用法

<Tabs groupId="framework" items={["Vanilla", "React", "Vue", "Astro"]} persist>
	<Tab value="Vanilla">
```js
import "@katorlys/oreui/radio-group";
```

```html
<ore-radio-group aria-label="World type">
  <ore-radio name="world" value="survival" checked>Survival</ore-radio>
  <ore-radio name="world" value="creative">Creative</ore-radio>
  <ore-radio name="world" value="hardcore" disabled>Hardcore</ore-radio>
```

    <Tab value="React">

```tsx
import { Radio, RadioGroup } from "@katorlys/oreui-react/radio-group";

export function WorldType() {
  return (
    <RadioGroup aria-label="World type">
      <Radio name="world" value="survival" checked>
        Survival
      </Radio>
      <Radio name="world" value="creative">
        Creative
      </Radio>
      <Radio name="world" value="hardcore" disabled>
        Hardcore
      </Radio>
    </RadioGroup>
  );
}
```

## 行为

Radio Group 提供 `role="radiogroup"` 和间距。  
更多信息请见 [Radio](../radio)。

## 无障碍

使用 `aria-label` 或 `aria-labelledby` 为每个组设置无障碍名称。所有子选项应共用一个 `name`。  
更多信息请见 [Radio](../radio#无障碍)。
