	<Tab value="React">
```tsx
import { OreTabButton } from "@katorlys/oreui-react/tab-button";
import { OreToggles } from "@katorlys/oreui-react/toggles";
import { useState } from "react";

export function DaylightToggles() {
	const [value, setValue] = useState("day");

	return (
		<OreToggles aria-label="Daylight cycle">
			<OreTabButton selected={value === "day"} onChange={() => setValue("day")}>Day</OreTabButton>
			<OreTabButton selected={value === "night"} onChange={() => setValue("night")}>Night</OreTabButton>
			<OreTabButton selected={value === "always"} onChange={() => setValue("always")}>Always</OreTabButton>
		</OreToggles>
	);
}
```

## Behavior
Toggles sets `role="tablist"`, lays out its children, and applies the `toggle` palette to direct and nested Tab Buttons.  
For more information, see [Tab Button](../../buttons/tab-button/).

## Accessibility
Give the tab group an accessible name. `Arrow keys` move through enabled options. `Home` and `End` select the first and last option.
