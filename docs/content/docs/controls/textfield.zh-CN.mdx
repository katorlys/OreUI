    <Tab value="React">

```tsx
import { Textfield } from "@oreui-web/react/textfield";
import { useState } from "react";

export function WorldNameField() {
  const [value, setValue] = useState("");

  return (
    <Textfield
      name="world"
      label="World name"
      description="Shown to other players"
      placeholder="New World"
      value={value}
      onInput={(event) => {
        const field = event.target as HTMLElement & { value: string };
        setValue(field.value);
      }}
    />
  );
}
```

## 验证

使用原生输入验证，或设置 `error` 来显示自定义验证信息。

```html
<ore-textfield label="Seed" type="number" required></ore-textfield>
<ore-textfield
  label="World name"
  error="This name is already in use"
></ore-textfield>
```

## 事件

Textfield 的值每次变化时都会触发 `input` 事件。其公共 `value` 属性会与内部输入保持同步。

## 无障碍

Textfield 会将标签、描述和验证信息与原生输入关联。请优先使用可见的 `label`；仅当可见标签不合适时，才使用 `aria-label`。
