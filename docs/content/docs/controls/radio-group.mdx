## Behavior

Radio Group provides `role="radiogroup"` and spacing.  
For more information, see [Radio](../radio).

## Accessibility

Give every group an accessible name with `aria-label` or `aria-labelledby`. All child options should share a `name`.  
For more information, see [Radio](../radio#accessibility).
