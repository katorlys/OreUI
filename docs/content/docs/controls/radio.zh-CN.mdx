## 用法

见 [Radio Group](../radio-group)。

## 状态

```html
<label>
  <input type="radio" name="mode" value="survival" checked />
  Survival
</label>
<label>
  <input type="radio" name="mode" value="hardcore" disabled />
  Hardcore
</label>
```

具有相同 `name` 且属于同一表单的 Radio 互斥。

## 事件

选择新选项会触发原生 `input` 和 `change` 事件。

## 属性

Radio 使用原生 input 的 `checked`、`disabled`、`name`、`required` 和 `value` 属性。OreUI 颜色使用 `data-color`。

## CSS 变量

| 变量                                    | 用途         |
| --------------------------------------- | ------------ |
| `--ore-radio-unit`                      | 基础尺寸单位 |
| `--ore-radio-background`                | 未选中背景   |
| `--ore-radio-highlight`                 | 未选中高光   |
| `--ore-radio-border`                    | 边框颜色     |
| `--ore-radio-indicator-light`           | 指示器亮色   |
| `--ore-radio-indicator-dim`             | 指示器中间色 |
| `--ore-radio-indicator-dark`            | 指示器暗色   |
| `--ore-radio-active-background`         | 选中背景     |
| `--ore-radio-active-background-hover`   | 选中悬停背景 |
| `--ore-radio-active-background-pressed` | 选中按下背景 |
| `--ore-radio-active-highlight`          | 选中高光     |
| `--ore-radio-active-highlight-hover`    | 选中悬停高光 |
| `--ore-radio-active-highlight-pressed`  | 选中按下高光 |

## 无障碍

原生 Radio input 提供相应的无障碍语义、表单行为和校验。使用方向键在同名组内移动，按空格键选择当前聚焦的选项。
