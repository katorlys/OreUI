## 用法

见 [Radio Group](../radio-group)。

## 颜色

```html
<ore-radio color="primary" checked>Primary</ore-radio>
<ore-radio color="secondary" checked>Secondary</ore-radio>
<ore-radio color="destructive" checked>Destructive</ore-radio>
<ore-radio color="dungeons" checked>Dungeons</ore-radio>
<ore-radio color="legends" checked>Legends</ore-radio>
<ore-radio color="realms" checked>Realms</ore-radio>
<ore-radio color="gold" checked>Gold</ore-radio>
```

## 状态

```html
<ore-radio name="mode" value="survival" checked>Survival</ore-radio>
<ore-radio name="mode" value="hardcore" disabled>Hardcore</ore-radio>
```

具有相同 `name` 且属于同一表单的 Radio 互斥。

## 事件

选择新选项会触发原生 `input` 和 `change` 事件。

## API

| Prop       | 属性       | 类型                                                                                         | 默认值      |
| ---------- | ---------- | -------------------------------------------------------------------------------------------- | ----------- |
| `checked`  | `checked`  | `boolean`                                                                                    | `false`     |
| `color`    | `color`    | `"primary" \| "secondary" \| "destructive" \| "dungeons" \| "legends" \| "realms" \| "gold"` | `"primary"` |
| `disabled` | `disabled` | `boolean`                                                                                    | `false`     |
| `name`     | `name`     | `string`                                                                                     | `""`        |
| `required` | `required` | `boolean`                                                                                    | `false`     |
| `value`    | `value`    | `string`                                                                                     | `"on"`      |

## CSS 变量

| 变量                                    | 用途         |
| --------------------------------------- | ------------ |
| `--ore-radio-unit`                      | 基础尺寸单位 |
| `--ore-radio-background`                | 未选中背景   |
| `--ore-radio-highlight`                 | 未选中高光   |
| `--ore-radio-border`                    | 边框颜色     |
| `--ore-radio-indicator-light`           | 指示器亮色   |
| `--ore-radio-indicator-dim`             | 指示器中间色 |
| `--ore-radio-indicator-dark`            | 指示器暗色   |
| `--ore-radio-active-background`         | 选中背景     |
| `--ore-radio-active-background-hover`   | 选中悬停背景 |
| `--ore-radio-active-background-pressed` | 选中按下背景 |
| `--ore-radio-active-highlight`          | 选中高光     |
| `--ore-radio-active-highlight-hover`    | 选中悬停高光 |
| `--ore-radio-active-highlight-pressed`  | 选中按下高光 |

## 无障碍

Radio 提供相应的无障碍语义。使用`方向键`在组内移动，按空格键选择当前聚焦的选项。
