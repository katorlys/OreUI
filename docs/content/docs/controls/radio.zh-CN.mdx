## 用法

见 [Radio Group](../radio-group)。

## 状态

```html
<ore-radio name="mode" value="survival" checked>Survival</ore-radio>
<ore-radio name="mode" value="hardcore" disabled>Hardcore</ore-radio>
```

具有相同 `name` 且属于同一表单的 Radio 互斥。

## 事件

选择新选项会触发原生 `input` 和 `change` 事件。

## API

| Prop       | 属性       | 类型      | 默认值  |
| ---------- | ---------- | --------- | ------- |
| `checked`  | `checked`  | `boolean` | `false` |
| `disabled` | `disabled` | `boolean` | `false` |
| `name`     | `name`     | `string`  | `""`    |
| `required` | `required` | `boolean` | `false` |
| `value`    | `value`    | `string`  | `"on"`  |

## 无障碍

Radio 提供相应的无障碍语义。使用`方向键`在组内移动，按空格键选择当前聚焦的选项。
