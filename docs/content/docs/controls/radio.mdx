## Usage

See [Radio Group](../radio-group).

## Colors

```html
<ore-radio color="primary" checked>Primary</ore-radio>
<ore-radio color="secondary" checked>Secondary</ore-radio>
<ore-radio color="destructive" checked>Destructive</ore-radio>
<ore-radio color="dungeons" checked>Dungeons</ore-radio>
<ore-radio color="legends" checked>Legends</ore-radio>
<ore-radio color="realms" checked>Realms</ore-radio>
<ore-radio color="gold" checked>Gold</ore-radio>
```

## States

```html
<ore-radio name="mode" value="survival" checked>Survival</ore-radio>
<ore-radio name="mode" value="hardcore" disabled>Hardcore</ore-radio>
```

Radios with the same `name` and form are mutually exclusive.

## Events

Selecting a new option dispatches native `input` and `change` events.

## API

| Property   | Attribute  | Type                                                                                         | Default     |
| ---------- | ---------- | -------------------------------------------------------------------------------------------- | ----------- |
| `checked`  | `checked`  | `boolean`                                                                                    | `false`     |
| `color`    | `color`    | `"primary" \| "secondary" \| "destructive" \| "dungeons" \| "legends" \| "realms" \| "gold"` | `"primary"` |
| `disabled` | `disabled` | `boolean`                                                                                    | `false`     |
| `name`     | `name`     | `string`                                                                                     | `""`        |
| `required` | `required` | `boolean`                                                                                    | `false`     |
| `value`    | `value`    | `string`                                                                                     | `"on"`      |

## CSS variables

| Variable                                | Purpose                     |
| --------------------------------------- | --------------------------- |
| `--ore-radio-unit`                      | Base size unit              |
| `--ore-radio-background`                | Unselected background       |
| `--ore-radio-highlight`                 | Unselected highlight        |
| `--ore-radio-border`                    | Border color                |
| `--ore-radio-indicator-light`           | Indicator light color       |
| `--ore-radio-indicator-dim`             | Indicator midtone color     |
| `--ore-radio-indicator-dark`            | Indicator dark color        |
| `--ore-radio-active-background`         | Selected background         |
| `--ore-radio-active-background-hover`   | Selected hover background   |
| `--ore-radio-active-background-pressed` | Selected pressed background |
| `--ore-radio-active-highlight`          | Selected highlight          |
| `--ore-radio-active-highlight-hover`    | Selected hover highlight    |
| `--ore-radio-active-highlight-pressed`  | Selected pressed highlight  |

## Accessibility

Radio provides radio semantics. Use `Arrow keys` to move within a group and `Space` to select the focused option.
