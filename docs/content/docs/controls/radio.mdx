## Usage

See [Radio Group](../radio-group).

## States

```html
<ore-radio name="mode" value="survival" checked>Survival</ore-radio>
<ore-radio name="mode" value="hardcore" disabled>Hardcore</ore-radio>
```

Radios with the same `name` and form are mutually exclusive.

## Events

Selecting a new option dispatches native `input` and `change` events.

## API

| Property   | Attribute  | Type      | Default |
| ---------- | ---------- | --------- | ------- |
| `checked`  | `checked`  | `boolean` | `false` |
| `disabled` | `disabled` | `boolean` | `false` |
| `name`     | `name`     | `string`  | `""`    |
| `required` | `required` | `boolean` | `false` |
| `value`    | `value`    | `string`  | `"on"`  |

## Accessibility

Radio provides radio semantics. Use `Arrow keys` to move within a group and `Space` to select the focused option.
