```tsx
import { Checkbox } from "@oreui-web/react/checkbox";
import { useState } from "react";

export function UpdatesCheckbox() {
  const [checked, setChecked] = useState(false);

  return (
    <Checkbox
      checked={checked}
      name="updates"
      value="yes"
      onChange={(event) => {
        setChecked(event.currentTarget.checked);
      }}
    >
      Receive updates
    </Checkbox>
  );
}
```

## 表单

勾选的项的值会包含在 `FormData` 中。重置表单会恢复初始的 `checked` 的状态。

```html
<form>
  <label>
    <input
      class="ore-checkbox"
      type="checkbox"
      name="terms"
      value="accepted"
      required
    />
    Accept the terms
  </label>
  <button type="submit">Continue</button>
  <button type="reset" data-color="secondary">Reset</button>
</form>
```

## 事件

原生 Checkbox 的值发生变化后会触发 `input` 和 `change` 事件。

## API

Checkbox 直接使用原生 `HTMLInputElement` API。`checked`、`disabled`、`name`、`required` 和 `value` 使用原生属性；只有 OreUI 配色使用 `data-color`。`checkValidity()`、`reportValidity()` 等原生方法保持可用。

## CSS 变量

| 变量                                       | 用途         |
| ------------------------------------------ | ------------ |
| `--ore-checkbox-unit`                      | 基础尺寸单位 |
| `--ore-checkbox-background`                | 未选中背景   |
| `--ore-checkbox-highlight`                 | 未选中高光   |
| `--ore-checkbox-border`                    | 边框颜色     |
| `--ore-checkbox-indicator`                 | 勾选标记颜色 |
| `--ore-checkbox-active-background`         | 选中背景     |
| `--ore-checkbox-active-background-hover`   | 选中悬停背景 |
| `--ore-checkbox-active-background-pressed` | 选中按下背景 |
| `--ore-checkbox-active-highlight`          | 选中高光     |
| `--ore-checkbox-active-highlight-hover`    | 选中悬停高光 |
| `--ore-checkbox-active-highlight-pressed`  | 选中按下高光 |

## 无障碍

原生 input 无需 JavaScript 就能提供 Checkbox 语义、label 激活、空格键操作、表单参与、校验和重置行为。
