import { Button } from "@oreui-web/react/button";
import { Dropdown } from "@oreui-web/react/dropdown";
import { useState } from "react";

export function GameModeDropdown() {
  const [value, setValue] = useState("creative");

    <Dropdown

## 变体

`borderless` 只在交互时才显示选项边框，而 `bordered` 会始终显示边框。

## 事件

| 事件     | 详情                                         |
| -------- | -------------------------------------------- |
| `change` | `{ item: HTMLButtonElement; value: string }` |
| `toggle` | 菜单派发的标准 Popover 事件                  |

对于 React，请使用 `onChange`。需要打开状态时，在菜单上监听 `toggle`。

## API

| Data 属性      | 类型                         | 默认值         |
| -------------- | ---------------------------- | -------------- |
| `data-value`   | `string`                     | `""`           |
| `data-variant` | `"bordered" \| "borderless"` | `"borderless"` |

## 公开类

| 类                            | 用途                     |
| ----------------------------- | ------------------------ |
| `.ore-dropdown-trigger`       | 打开菜单的按钮           |
| `.ore-dropdown-trigger-label` | 根据所选菜单项更新的文本 |
| `.ore-dropdown-menu`          | 弹出菜单                 |
| `.ore-dropdown-item`          | 可选择的菜单项           |

## CSS 变量

菜单的可滚动区域也可使用所有的 [Scrollbar CSS 变量](../../navigation/scrollbar#css-变量)。

| 变量                                   | 用途                   |
| -------------------------------------- | ---------------------- |
| `--ore-dropdown-unit`                  | 基础尺寸单位           |
| `--ore-dropdown-menu-background`       | 菜单背景颜色           |
| `--ore-dropdown-menu-outline`          | 菜单轮廓颜色           |
| `--ore-dropdown-item-background`       | 菜单项背景             |
| `--ore-dropdown-item-background-hover` | 菜单项悬停背景         |
| `--ore-dropdown-item-border`           | 菜单项之间的分隔线颜色 |
| `--ore-dropdown-foreground`            | 菜单项文本和图标颜色   |
| `--ore-dropdown-visible-items`         | 滚动前可见的菜单项数量 |

## 无障碍

Dropdown 管理菜单角色、选中状态和焦点，支持`方向键`、`Home`、`End`、`Enter`、空格键、`Esc` 和 `Tab` 键。  
对于不可用的菜单项，请使用原生 `disabled` 属性。
