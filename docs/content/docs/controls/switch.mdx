```tsx
import { Switch } from "@oreui-web/react/switch";
import { useState } from "react";

export function AutosaveSwitch() {
  const [checked, setChecked] = useState(false);

  return (
    <Switch
      checked={checked}
      name="autosave"
      value="enabled"
      variant="icons"
      onChange={(event) => {
        setChecked(event.currentTarget.checked);
      }}
    >
      Enable autosave
    </Switch>
  );
}
```

## Forms

Checked values are included in `FormData`, and reset restores the initial state.

## Events

The native input dispatches `input` and `change` events after its checked state changes.

## Attributes

Switch uses the native checkbox attributes `checked`, `disabled`, `name`, `required`, and `value`. Add the `ore-switch` class and `role="switch"` for switch semantics. OreUI options use `data-color` and `data-variant="icons"`.

## CSS variables

| Variable                               | Purpose                   |
| -------------------------------------- | ------------------------- |
| `--ore-switch-unit`                    | Base size unit            |
| `--ore-switch-track-background`        | Inactive track background |
| `--ore-switch-track-highlight`         | Inactive track highlight  |
| `--ore-switch-track-border`            | Track border color        |
| `--ore-switch-thumb-background`        | Thumb background          |
| `--ore-switch-thumb-highlight`         | Thumb highlight           |
| `--ore-switch-thumb-shadow`            | Thumb shadow              |
| `--ore-switch-thumb-border`            | Thumb border color        |
| `--ore-switch-active-track-background` | Active track background   |
| `--ore-switch-active-track-highlight`  | Active track highlight    |
| `--ore-switch-icon`                    | Thumb icon color          |

## Accessibility

The native checkbox provides form and keyboard behavior, while `role="switch"` exposes switch semantics. Use a label to describe the control.
