## 默认状态

```html
<details class="ore-accordion" open>
  <summary>Details</summary>
  <div class="ore-accordion-content">World settings</div>
</details>
```

## 受控状态

状态受应用控制时，设置元素属性，并监听变化：

```ts
const accordion = document.querySelector<HTMLDetailsElement>(".ore-accordion");

if (accordion) {
  accordion.open = true;
  accordion.addEventListener("toggle", () => {
    console.log(accordion.open);
  });
}
```

## 无障碍检查清单

- [ ] 为只含图标的控件添加 `aria-label`。
- [ ] 使用原生标题、表格、链接和表单标签。
- [ ] 使焦点样式清晰可见。
- [ ] 避免覆盖原生控件管理的键盘操作和 ARIA 状态。
- [ ] 将错误信息和帮助文本放在组件文档说明的公开部分中。
