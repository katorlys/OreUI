## Default state

```html
<details class="ore-accordion" open>
  <summary>Details</summary>
  <div class="ore-accordion-content">World settings</div>
</details>
```

## Controlled state

When the application controls the state, set the element property, and listen for changes:

```ts
const accordion = document.querySelector<HTMLDetailsElement>(".ore-accordion");

if (accordion) {
  accordion.open = true;
  accordion.addEventListener("toggle", () => {
    console.log(accordion.open);
  });
}
```

## Accessibility checklist

- [ ] Add `aria-label` to icon-only controls.
- [ ] Use native headings, tables, links, and form labels.
- [ ] Keep focus styles visible.
- [ ] Avoid overriding keyboard handling or ARIA state managed by native controls.
- [ ] Place errors and help text in the component's documented public parts.
