title: Styling

---

Import the default styles once in your application:

```css
@import "oreui-web/styles.css";
```

## Classes

Apply classes to the component to override default styles.

```html
<ore-button class="danger-action" type="button">Delete</ore-button>
```

```css
.danger-action {
  background: #ca3636;
  color: white;
  min-height: 3rem;
}

.danger-action:hover {
  background: #d54242;
}
```

## CSS variables

Modify CSS variables to change default styles.

```html
<ore-switch class="large-thumb">Music</ore-switch>
```

```css
.large-thumb {
  --ore-switch-thumb-size: 1.25rem;
}
```

## TailwindCSS

Use standard utilities for properties such as sizing and spacing. To preserve a component's state styles, customize its public `--ore-*` variables with arbitrary property utilities.

```html
<ore-button
  class="min-h-12 [--ore-button-background-default:#dc2626] [--ore-button-background-hover:#ef4444] [--ore-button-background-pressed:#b91c1c] [--ore-button-foreground:white]"
  type="button"
>
  Delete
</ore-button>
```

The Button background draws its face, highlight, border, and shadow together, so a `bg-*` utility would replace that drawing instead of only changing its color.

## PandaCSS

PandaCSS can generate a class that sets the same public variables. Apply the returned class name using your framework's normal class binding.

```tsx
import { css } from "../styled-system/css";

const dangerAction = css({
  minHeight: "3rem",
  "--ore-button-background-default": "#dc2626",
  "--ore-button-background-hover": "#ef4444",
  "--ore-button-background-pressed": "#b91c1c",
  "--ore-button-foreground": "white",
});

<ore-button className={dangerAction} type="button">
  Delete
</ore-button>;
```
