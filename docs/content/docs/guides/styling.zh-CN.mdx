---

先在应用程序中导入一次默认样式：

```css
@import "oreui-web/styles.css";
```

## Class

在组件上使用 class 即可覆盖默认样式。

```html
<ore-button class="danger-action" type="button">Delete</ore-button>
```

```css
.danger-action {
  background: #ca3636;
  color: white;
  min-height: 3rem;
}

.danger-action:hover {
  background: #d54242;
}
```

## CSS 变量

在 CSS 中修改变量以更改默认样式。

```html
<ore-switch class="large-thumb">Music</ore-switch>
```

```css
.large-thumb {
  --ore-switch-thumb-size: 1.25rem;
}
```

## TailwindCSS

尺寸、间距等属性可以直接使用现成 utility。若要保留组件的状态样式，可使用任意属性 utility 覆盖组件公开的 `--ore-*` 变量。

```html
<ore-button
  class="min-h-12 [--ore-button-background-default:#dc2626] [--ore-button-background-hover:#ef4444] [--ore-button-background-pressed:#b91c1c] [--ore-button-foreground:white]"
  type="button"
>
  Delete
</ore-button>
```

Button 的背景会同时绘制表面、高光、边框和阴影，因此单纯地 `bg-*` utility 会导致整套绘制被替换，而不仅仅是改变颜色。

## PandaCSS

PandaCSS 可以生成设置相同公开变量的 class。使用框架通常的 class 绑定方式应用 `css()` 返回的 class 名称即可。

```tsx
import { css } from "../styled-system/css";

const dangerAction = css({
  minHeight: "3rem",
  "--ore-button-background-default": "#dc2626",
  "--ore-button-background-hover": "#ef4444",
  "--ore-button-background-pressed": "#b91c1c",
  "--ore-button-foreground": "white",
});

<ore-button className={dangerAction} type="button">
  Delete
</ore-button>;
```
