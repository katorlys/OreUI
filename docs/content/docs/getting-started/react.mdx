## Install

```bash tab="pnpm"
pnpm add @katorlys/oreui-react
```

```bash tab="yarn"
yarn add @katorlys/oreui-react
```

```bash tab="npm"
npm install @katorlys/oreui-react
```

```bash tab="bun"
bun add @katorlys/oreui-react
```

## Add styles

Import the stylesheet once in your app entry:

```ts
import "@katorlys/oreui-react/styles.css";
```

## Use a component

```tsx title="App.tsx"
import { Button } from "@katorlys/oreui-react/button";

export function App() {
  return <Button type="button">Create new world</Button>;
}
```

<Callout type="info">
  To use all the components from the package root, import
  `@katorlys/oreui-react`.
</Callout>

## Examples

Typed events:

```tsx title="GameMode.tsx"
import { Button } from "@katorlys/oreui-react/button";
import { Dropdown } from "@katorlys/oreui-react/dropdown";

export function GameMode() {
  return (
    <Dropdown
      onChange={(event) => console.log(event.detail.value)}
      onOpenChange={(event) => console.log(event.detail)}
    >
      <Button className="ore-dropdown-trigger" type="button">
        Game mode
      </Button>
      <div className="ore-dropdown-menu">
        <button className="ore-dropdown-item" data-value="survival">
          Survival
        </button>
      </div>
    </Dropdown>
  );
}
```

The React wrappers forward `children`, `className`, properties, aria attributes, as well as refs.

<Callout type="warn">
  Currently, OreUI React only supports client applications. We may extend
  support to server components and server-side rendering in the future.
</Callout>
