## Install

```bash tab="pnpm"
pnpm add oreui-web
```

```bash tab="yarn"
yarn add oreui-web
```

```bash tab="npm"
npm install oreui-web
```

```bash tab="bun"
bun add oreui-web
```

## Use a component

Import styles in a shared layout:

```astro title="src/layouts/Layout.astro"
---
import "oreui-web/styles.css";
---

<slot />
```

Use native HTML after importing the shared stylesheet:

```astro title="src/pages/index.astro"
<button type="button">Create new world</button>
```

<Callout type="info">To use all the components, import `oreui-web`.</Callout>

## Examples

Forms and events:

```astro title="src/pages/account.astro"
<form id="account">
  <label><input type="checkbox" name="terms" required />Accept terms</label>
  <button type="submit">Continue</button>
</form>

<script>
  const form = document.querySelector<HTMLFormElement>("#account");

  form?.addEventListener("submit", (event) => {
    event.preventDefault();
    console.log(new FormData(form).get("terms"));
  });
</script>
```

<Callout type="warn">`is:inline` cannot bundle package imports.</Callout>
