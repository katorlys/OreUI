## 安装

```bash tab="pnpm"
pnpm add @oreui-web/react
```

```bash tab="yarn"
yarn add @oreui-web/react
```

```bash tab="npm"
npm install @oreui-web/react
```

```bash tab="bun"
bun add @oreui-web/react
```

## 添加样式

在 app entry 中导入一次样式表即可：

```ts
import "@oreui-web/react/styles.css";
```

## 使用组件

```tsx title="App.tsx"
import { Button } from "@oreui-web/react/button";

export function App() {
  return <Button type="button">Create new world</Button>;
}
```

<Callout type="info">导入 `@oreui-web/react` 即可使用所有组件。</Callout>

## 示例

事件：

```tsx title="GameMode.tsx"
import { Button } from "@oreui-web/react/button";
import { Dropdown } from "@oreui-web/react/dropdown";

export function GameMode() {
  return (
    <Dropdown
      onChange={(event) => console.log(event.detail.value)}
      onOpenChange={(event) => console.log(event.detail)}
    >
      <Button className="ore-dropdown-trigger" type="button">
        Game mode
      </Button>
      <div className="ore-dropdown-menu">
        <button className="ore-dropdown-item" data-value="survival">
          Survival
        </button>
      </div>
    </Dropdown>
  );
}
```

React 封装组件会转发 `children`、`className`、属性、aria 属性 以及 ref。

<Callout type="warn">
  OreUI React
  目前仅支持客户端应用。未来可能会增加对服务器组件和服务端渲染的支持。
</Callout>
