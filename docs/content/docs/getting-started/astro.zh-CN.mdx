## 安装

```bash tab="pnpm"
pnpm add oreui-web
```

```bash tab="yarn"
yarn add oreui-web
```

```bash tab="npm"
npm install oreui-web
```

```bash tab="bun"
bun add oreui-web
```

## 使用组件

在共享 Layout 中导入样式：

```astro title="src/layouts/Layout.astro"
---
import "oreui-web/styles.css";
---

<slot />
```

在客户端脚本中注册组件：

```astro title="src/pages/index.astro"
<ore-button type="button">Create new world</ore-button>

<script>
  import "oreui-web/button";
</script>
```

<Callout type="info">导入 `oreui-web` 即可使用所有组件。</Callout>

## 示例

表单与事件：

```astro title="src/pages/account.astro"
<form id="account">
  <ore-checkbox name="terms" required>Accept terms</ore-checkbox>
  <ore-button type="submit">Continue</ore-button>
</form>

<script>
  import "oreui-web/button";
  import "oreui-web/checkbox";

  const form = document.querySelector<HTMLFormElement>("#account");

  form?.addEventListener("submit", (event) => {
    event.preventDefault();
    console.log(new FormData(form).get("terms"));
  });
</script>
```

<Callout type="warn">请勿使用 `is:inline` 打包软件包导入。</Callout>
