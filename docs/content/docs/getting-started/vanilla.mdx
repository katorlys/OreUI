## Install

```bash tab="pnpm"
pnpm add oreui-web
```

```bash tab="yarn"
yarn add oreui-web
```

```bash tab="npm"
npm install oreui-web
```

```bash tab="bun"
bun add oreui-web
```

### Use from CDN

You can use a CDN to avoid installing any dependencies.

```html title="index.html"
<link
  rel="stylesheet"
  href="https://cdn.jsdelivr.net/npm/oreui-web@latest/dist/styles.css"
/>

<ore-button type="button">Create new world</ore-button>

<script type="module">
  import "https://cdn.jsdelivr.net/npm/oreui-web@latest/+esm";
</script>
```

<Callout type="info">
  In production you should pin an exact version, for example, `oreui-web@0.1.0`.
</Callout>

## Use a component

```js title="script.js"
import "oreui-web/styles.css";
import "oreui-web/button";
```

```html title="index.html"
<ore-button type="button">Create new world</ore-button>
```

<Callout type="info">To use all the components, import `oreui-web`.</Callout>

## Examples

Forms:

```html title="index.html"
<form id="account">
  <ore-checkbox name="terms" required>Accept terms</ore-checkbox>
  <ore-button type="submit">Continue</ore-button>
</form>
```

Events:

```js title="script.js"
const form = document.querySelector < HTMLFormElement > "#account";

form?.addEventListener("submit", (event) => {
  event.preventDefault();
  console.log(new FormData(form).get("terms"));
});
```
