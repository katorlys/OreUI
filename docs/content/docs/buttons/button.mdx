## Disabled

```html

```

## Forms

The default `type` is `submit`. Set `type="button"` when the button should not submit its form.

```html
<form>
  <ore-button type="submit">Save</ore-button>
  <ore-button type="reset" color="secondary">Reset</ore-button>
</form>
```

## API

| Property   | Attribute  | Type                                                                                         | Default     |
| ---------- | ---------- | -------------------------------------------------------------------------------------------- | ----------- |
| `color`    | `color`    | `"destructive" \| "dungeons" \| "gold" \| "legends" \| "primary" \| "realms" \| "secondary"` | `"primary"` |
| `disabled` | `disabled` | `boolean`                                                                                    | `false`     |
| `type`     | `type`     | `"button" \|"reset" \|"submit"`                                                              | `"submit"`  |
| `variant`  | `variant`  | `"default" \| "hero"`                                                                        | `"default"` |

## Accessibility

The component uses button semantics and supports `Enter` and `Space`. Disabled buttons are removed from the tab and expose `aria-disabled="true"`.
