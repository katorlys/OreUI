## Variants

```html
<button class="ore-button" data-variant="default">Default</button>
<button class="ore-button" data-variant="hero">Hero</button>
```

## Disabled

```html
<button class="ore-button" disabled>Unavailable</button>
```

## Loading

Set `data-loading` while an action is in progress, and keep the native button disabled with `aria-busy="true"`. Framework bindings do this mapping when their `loading` prop is set.

```html
<button class="ore-button" data-loading aria-busy="true" disabled>
  Saving
</button>
```

## Prefix and suffix

Use the public `.ore-button-prefix` and `.ore-button-suffix` classes to place presentational elements around the label.

<ButtonAffixesPreview />

```html
<button class="ore-button" type="button">
  <img class="ore-button-prefix" src="/icons/arrow-left.svg" alt="" />
  Back
</button>

<button class="ore-button" type="button">
  Continue
  <img class="ore-button-suffix" src="/icons/arrow-right.svg" alt="" />
</button>
```

## Links

Use a native anchor with `class="ore-button"` for navigation. It preserves browser behaviors such as opening in a new tab, copying the link, and downloading a resource.

<LinkButtonPreview />

```html
<a
  class="ore-button"
  href="https://example.com"
  target="_blank"
  rel="noreferrer"
>
  Open website
</a>
```

Use a link button for navigation and a regular button for actions. Anchors do not support `disabled`; omit `href` or remove the link when navigation is unavailable.

## Forms

The default `type` is `button`. Set `type="submit"` explicitly for a submit button. `name` and `value` are included only when that button submits the form. Use `form` to associate a button outside the form with a form ID.

```html
<form id="settings">
  <button type="submit" name="action" value="save">Save</button>
  <button type="reset" data-color="secondary">Reset</button>
</form>

<button type="submit" form="settings" name="action" value="save-and-close">
  Save and close
</button>
```

## API

Button uses the native `HTMLButtonElement` API. Use native attributes such as `disabled`, `form`, `name`, `type`, and `value`; use `data-color`, `data-variant`, and `data-loading` only for OreUI visual configuration.

## Accessibility

Native buttons provide form participation, validation, focus, `Enter`, and `Space` behavior without a controller. Native anchors provide standard link semantics and navigation. Loading buttons remain disabled and expose `aria-busy="true"`.
