## 加载中

操作进行时设置 `data-loading`，并同时保留原生 `disabled` 和 `aria-busy="true"`。框架 wrapper 会在设置 `loading` prop 时完成这些映射。

```html
<button data-loading aria-busy="true" disabled>Saving</button>
```

## 前后缀

使用公开的 `.ore-button-prefix` 和 `.ore-button-suffix` 类，在标签前后放置展示性元素。

<ButtonAffixesPreview />

```html
<button type="button">
  <img class="ore-button-prefix" src="/icons/arrow-left.svg" alt="" />
  Back
</button>

<button type="button">
  Continue
  <img class="ore-button-suffix" src="/icons/arrow-right.svg" alt="" />
</button>
```

## 链接

页面导航使用带 `class="button"` 的原生锚点，并保留在新标签页打开、复制链接和下载资源等浏览器行为。

<LinkButtonPreview />

```html
<a class="button" href="https://example.com" target="_blank" rel="noreferrer">
  Open website
</a>
```

页面导航应使用链接按钮，触发操作则使用普通按钮。锚点不支持 `disabled`；导航不可用时应移除 `href` 或移除该链接。

## 表单

默认的 `type` 为 `button`，提交按钮需要显式设置 `type="submit"`。只有触发表单提交的按钮才会提交自己的 `name` 和 `value`。使用 `form` 可将表单外的按钮关联到指定 ID 的表单。

```html
<form id="settings">
  <button type="submit" name="action" value="save">Save</button>
  <button type="reset" data-color="secondary">Reset</button>
</form>

<button type="submit" form="settings" name="action" value="save-and-close">
  Save and close
</button>
```

## API

Button 直接使用原生 `HTMLButtonElement` API。`disabled`、`form`、`name`、`type`、`value` 等使用原生属性；只有 OreUI 视觉配置使用 `data-color`、`data-variant` 和 `data-loading`。

## CSS 变量

| 变量                              | 用途           |
| --------------------------------- | -------------- |
| `--ore-button-unit`               | 基础尺寸单位   |
| `--ore-button-background-default` | 默认表面背景   |
| `--ore-button-background-hover`   | 悬停表面背景   |
| `--ore-button-background-pressed` | 按下表面背景   |
| `--ore-button-highlight-default`  | 默认顶部高光   |
| `--ore-button-highlight-hover`    | 悬停顶部高光   |
| `--ore-button-highlight-pressed`  | 按下顶部高光   |
| `--ore-button-border`             | 边框颜色       |
| `--ore-button-shadow`             | 底部阴影颜色   |
| `--ore-button-foreground`         | 文本和图标颜色 |
| `--ore-button-font-family`        | 标签字体       |
| `--ore-button-font-size`          | 标签字号       |
| `--ore-button-text-shadow`        | 标签文本阴影   |

## 无障碍

原生按钮无需 controller 即可提供表单参与、校验、焦点、`Enter` 和 `Space` 行为。原生锚点提供标准链接语义和导航。加载中的按钮保持禁用，并提供 `aria-busy="true"`。
