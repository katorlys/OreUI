## 变体

```html
<ore-button variant="primary">Primary</ore-button>
<ore-button variant="secondary">Secondary</ore-button>
<ore-button variant="hero">Hero</ore-button>
<ore-button variant="destructive">Delete</ore-button>
```

## Disabled

```html
<ore-button disabled>Unavailable</ore-button>
```

## 表单

默认的 `type` 为 `submit`。当按钮不应提交表单时，需设置 `type="button"`。

```html
<form>
  <ore-button type="submit">Save</ore-button>
  <ore-button type="reset" variant="secondary">Reset</ore-button>
</form>
```

## API

| Prop       | 属性       | 类型                                               | 默认值      |
| ---------- | ---------- | -------------------------------------------------- | ----------- |
| `disabled` | `disabled` | `boolean`                                          | `false`     |
| `type`     | `type`     | `"button" \|"reset" \|"submit"`                    | `"submit"`  |
| `variant`  | `variant`  | `"destructive" \|"hero" \|"primary" \|"secondary"` | `"primary"` |

## 无障碍

该组件使用按钮语义，并支持 `Enter` 和 `Space` 键。禁用的按钮不会被 Tab 键选中，并带有 `aria-disabled="true"`。
