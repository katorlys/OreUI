## 表单

默认的 `type` 为 `submit`。当按钮不应提交表单时，需设置 `type="button"`。

```html
<form>
  <ore-button type="submit">Save</ore-button>
  <ore-button type="reset" color="secondary">Reset</ore-button>
</form>
```

## API

| Prop       | 属性       | 类型                                                                                         | 默认值      |
| ---------- | ---------- | -------------------------------------------------------------------------------------------- | ----------- |
| `color`    | `color`    | `"destructive" \| "dungeons" \| "gold" \| "legends" \| "primary" \| "realms" \| "secondary"` | `"primary"` |
| `disabled` | `disabled` | `boolean`                                                                                    | `false`     |
| `type`     | `type`     | `"button" \|"reset" \|"submit"`                                                              | `"submit"`  |
| `variant`  | `variant`  | `"default" \| "hero"`                                                                        | `"default"` |

## CSS 变量

| 变量                              | 用途           |
| --------------------------------- | -------------- |
| `--ore-button-unit`               | 基础尺寸单位   |
| `--ore-button-background-default` | 默认表面背景   |
| `--ore-button-background-hover`   | 悬停表面背景   |
| `--ore-button-background-pressed` | 按下表面背景   |
| `--ore-button-highlight-default`  | 默认顶部高光   |
| `--ore-button-highlight-hover`    | 悬停顶部高光   |
| `--ore-button-highlight-pressed`  | 按下顶部高光   |
| `--ore-button-border`             | 边框颜色       |
| `--ore-button-shadow`             | 底部阴影颜色   |
| `--ore-button-foreground`         | 文本和图标颜色 |
| `--ore-button-font-family`        | 标签字体       |
| `--ore-button-font-size`          | 标签字号       |
| `--ore-button-text-shadow`        | 标签文本阴影   |

## 无障碍

该组件使用按钮语义，并支持 `Enter` 和 `Space` 键。禁用的按钮不会被 Tab 键选中，并带有 `aria-disabled="true"`。
