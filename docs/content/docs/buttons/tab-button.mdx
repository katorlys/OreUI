title: Tab Button
description: The base component for Tab Bar.
---

This should only be used in Tab Bar components, which makes selection and keyboard navigation work as a group.

## Usage

Place tab buttons inside any element with `role="tablist"`.

## Palettes

```html
<button
  class="ore-tab-button"
  data-palette="default"
  role="tab"
  aria-selected="true"
>
  Worlds
</button>
<button
  class="ore-tab-button"
  data-palette="toggle"
  role="tab"
  aria-selected="true"
>
  Enabled
</button>
```

## Events

Tab Button dispatches `change` after it becomes selected.

```js
const tab = document.querySelector(".ore-tab-button");
tab?.addEventListener("change", () =>
  console.log(tab.getAttribute("aria-selected")),
);
```

## API

| Property   | Attribute       | Type                            | Default     |
| ---------- | --------------- | ------------------------------- | ----------- |
| `disabled` | `disabled`      | `boolean`                       | `false`     |
| `palette`  | `data-palette`  | `"default" \|"toggle"`          | `"default"` |
| `selected` | `aria-selected` | `"true" \|"false"`              | `"false"`   |
| `type`     | `type`          | `"button" \|"reset" \|"submit"` | `"button"`  |

| Event    | Detail |
| -------- | ------ |
| `change` | None   |

## CSS variables

Tab Button also accepts all [Button CSS variables](../button#css-variables).

| Variable                           | Purpose                       |
| ---------------------------------- | ----------------------------- |
| `--ore-tab-off-background`         | Unselected background         |
| `--ore-tab-off-background-hover`   | Unselected hover background   |
| `--ore-tab-off-background-pressed` | Unselected pressed background |
| `--ore-tab-off-highlight`          | Unselected highlight          |
| `--ore-tab-off-highlight-hover`    | Unselected hover highlight    |
| `--ore-tab-off-highlight-pressed`  | Unselected pressed highlight  |
| `--ore-tab-off-shadow`             | Unselected shadow             |
| `--ore-tab-off-foreground`         | Unselected text color         |
| `--ore-tab-on-background`          | Selected background           |
| `--ore-tab-on-highlight`           | Selected highlight            |
| `--ore-tab-on-foreground`          | Selected text color           |
| `--ore-tab-indicator`              | Selection indicator color     |

## Accessibility

Tab Button is a native `button` with `role="tab"`. The Tab Bar controller updates `aria-selected`. `Arrow keys` move through tabs that are not disabled, while `Home` and `End` select the first and last tab.
