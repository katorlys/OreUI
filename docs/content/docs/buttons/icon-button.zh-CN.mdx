## API

Icon Button 继承 Button 的 API。

| Prop       | 属性       | 类型                            | 默认值     |
| ---------- | ---------- | ------------------------------- | ---------- |
| `disabled` | `disabled` | `boolean`                       | `false`    |
| `type`     | `type`     | `"button" \|"reset" \|"submit"` | `"submit"` |

## 无障碍

在 `aria-label` 中描述操作。按钮内的图标应使用 `aria-hidden="true"`。
