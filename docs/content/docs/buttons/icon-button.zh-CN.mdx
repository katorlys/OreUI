## API

Icon Button 继承 Button 的 API。

| Prop       | 属性       | 类型                            | 默认值     |
| ---------- | ---------- | ------------------------------- | ---------- |
| `disabled` | `disabled` | `boolean`                       | `false`    |
| `type`     | `type`     | `"button" \|"reset" \|"submit"` | `"submit"` |

## CSS 变量

| 变量                             | 用途             |
| -------------------------------- | ---------------- |
| `--ore-icon-button-unit`         | 基础尺寸单位     |
| `--ore-icon-button-background`   | 表面背景颜色     |
| `--ore-icon-button-highlight`    | 顶部高光颜色     |
| `--ore-icon-button-shadow-color` | 底部阴影颜色     |
| `--ore-icon-button-corner`       | 边角强调色       |
| `--ore-icon-button-border`       | 边框颜色         |
| `--ore-icon-button-foreground`   | 图标和文本颜色   |
| `--ore-icon-button-place-items`  | 内部网格项目对齐 |
| `--ore-icon-button-width`        | 按钮宽度         |
| `--ore-icon-button-height`       | 按钮高度         |
| `--ore-icon-button-padding`      | 内边距           |
| `--ore-icon-button-box-shadow`   | 额外外部盒阴影   |

## 无障碍

在 `aria-label` 中描述操作。按钮内的图标应使用 `aria-hidden="true"`。
