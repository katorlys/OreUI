# @oreui-web/solid
OreUI for SolidJS applications.

## Install
```bash
pnpm add @oreui-web/solid
```
```bash
yarn add @oreui-web/solid
```
```bash
npm install @oreui-web/solid
```
```bash
bun add @oreui-web/solid
```
