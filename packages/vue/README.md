# OreUI Vue
OreUI for Vue applications.

## Install
```bash
pnpm add @katorlys/oreui-vue
```
```bash
yarn add @katorlys/oreui-vue
```
```bash
npm install @katorlys/oreui-vue
```
```bash
bun add @katorlys/oreui-vue
```

## Documentation
For full documentation, please visit [lab.katorly.com/OreUI](https://lab.katorly.com/OreUI/docs/getting-started/vue).
