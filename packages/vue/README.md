# @oreui-web/vue
OreUI for Vue applications.

An unofficial fan-made component library that brings Minecraft's Ore UI design system to your web projects.

## Install
```bash
pnpm add @oreui-web/vue
```
```bash
yarn add @oreui-web/vue
```
```bash
npm install @oreui-web/vue
```
```bash
bun add @oreui-web/vue
```

## Documentation
For full documentation, please visit [katorly.dev/OreUI](https://katorly.dev/OreUI/docs/getting-started/vue).
